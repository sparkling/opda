# OPDA design archive

This directory is retained for provenance only. For current OPDA interface work:

1. Read `../DESIGN.md`.
2. Use the original assets from `../public/ui/brand/` without altering their
   geometry or embedded colours.
3. Use `../public/ui/design-tokens.css` and the modules imported by
   `../public/ui/design-system.css`.
4. Classify each decision as authoritative supplied evidence, observed evidence or
   a derived decision.
5. Update the design contract test with any contract change.

The prototype files and ZIP packages beside this note are not templates for new
pages and contain obsolete setup and styling choices.
