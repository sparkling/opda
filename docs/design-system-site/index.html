03

Brand

Original assets, exact colours

Preserve

Geometry, proportions and embedded SVG values #131224, #FEC82F and #FEC92B.

Separate roles

Logo-specific values stay inside the source assets; interface amber remains #FEC92B.

Photography

Real people collaborating and real property, with rights, focal point and alt-text decisions recorded.

Motif

One 4px amber rule. No reconstructed house marks, ambient patterns or decorative gradients.

Photography gate

No image enters the system until provenance and usage rights are recorded. Generative identity imagery is excluded.

07

Patterns

Meaning before page furniture

01 · Standard

Status → definition → examples → implementation

Owner, version and review date precede normative content.

02 · Evidence

Source → claim → classification → confidence

Quoted, inferred and proposed statements remain visibly different.

03 · Data browser

Query → applied filters → results → outcomes

Dense controls stay labelled, keyboard reachable and stateful.

04 · Governance

Proposal → review → disposition → adoption

Publication never implies ratification.

Accessibility

Binary release gates

44Minimum target in both dimensions, except inline prose links.
320CSS pixels reflow without loss; verified again at 400% zoom.
2+2Two-colour focus ring: amber and ink on every interactive control.
  • ✓ Complete keyboard paths; Escape and focus return for drawers/dialogs.
  • ✓ Status always has an icon and complete text label.
  • ✓ Forced-colour and reduced-motion equivalents.
  • ✓ Labels, captions and alt/decorative decisions are explicit.
  • ✓ Tables use captions, header scope, labelled overflow and aria-sort.
09

Governance

One contract, traceable change

  1. EvidenceClassify the input as Authoritative, Observed or Derived.
  2. DecisionUpdate DESIGN.md or record a proportionate ADR.
  3. ProjectionChange tokens, components and the presentation together.
  4. ProofPass contrast, interaction, build and visual regression gates.
  5. ReleaseVersion the contract; publication remains separately authorised.
