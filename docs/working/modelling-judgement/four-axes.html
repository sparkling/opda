Four questions, one justified classification

Identity, rigidity, dependence and unity constrain the same modelling judgement. They are not four sequential steps or a machine proof.

Light

Dark

  1. Identity: say what makes an instance this very thing, and when that identity ends.
  2. Rigidity: ask whether it can cease to instantiate this type while remaining the same thing.
  3. Dependence: identify the bearer or bearers without which it cannot exist.
  4. Unity: justify what makes the parts one whole, or explicitly identify no unity.
  5. Integrate all four answers into a justified classification and review its asserted hierarchy; automated checks can test declared commitments, not supply their justification.
