Check applicability before checking the requirement

The fictional rule requires a named limitation when a report explicitly states limited access. If the antecedent is missing, applicability is not established.

Reading the figure

  1. The stated teaching convention: when a report explicitly says access was limited, it must identify the reported limitation.
  2. Limited access plus a named locked enclosed area: the rule applies and the requirement is met.
  3. Limited access with no named limitation: the rule applies and the requirement is unmet.
  4. No access statement: applicability is not established. Do not invent a pass, a failed requirement or non-applicability from the missing antecedent.
