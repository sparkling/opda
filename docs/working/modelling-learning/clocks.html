Reading the figure

  1. Inspection occurrence: the fictional visit spans 2–3 September.
  2. Assessment applicability: the assessment is explicitly about 3 September only; this is not a validity guarantee.
  3. Report issue: 5 September. Recording in a system: 8 September.
  4. The horizontal scale is one day per equal interval. The lanes describe different questions, not four stages of a workflow.
