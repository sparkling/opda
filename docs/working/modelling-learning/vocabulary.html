Topic hierarchy is not physical containment

Roof condition is a narrower topic than Building fabric. That topic relationship does not say that a roof condition is a physical part of a building.

Reading the figure

  1. Building fabric and Roof condition are topics. Roof condition is a narrower topic, not a physical component.
  2. A physical roof being part of a building is a different relationship between different kinds of subjects.
  3. Access outcome is a separate controlled choice for a nonempty identified set of areas: all, some-but-not-all, or none. A missing value is not a fourth outcome.
